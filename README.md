# Atlas AeroSystems website

The website for Atlas AeroSystems, Inc. It is plain HTML and CSS, so there is no build step. GitHub Pages serves these files exactly as they are.

## What's in here

| File | What it is |
| --- | --- |
| `index.html` | Home page |
| `about.html` | About Us page |
| `people.html` | People page |
| `contact.html` | Contact page |
| `styles.css` | Colors, fonts and layout for every page |
| `images/` | Logo, icons and headshots resized for the web |
| `.nojekyll` | Tells GitHub Pages to serve the files exactly as they are |

The original uploads (`Full Logo.png` and the four headshots) are kept unchanged in the main folder. The website uses the smaller copies in `images/`.

## Making simple text changes

1. On github.com, open the page's file, for example `people.html`.
2. Click the pencil icon ("Edit this file").
3. Change the words you see between the tags, for example between `<li>` and `</li>`. Don't change anything inside the `< >` brackets.
4. Click **Commit changes**. The live site updates within a minute or two.

## Replacing a headshot

Upload a square photo into the `images` folder using the **same file name** as the photo you're replacing, for example `images/justin-pope.jpg`.
